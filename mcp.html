Modkeel in your AI assistant

Modkeel's MCP server lets Claude, ChatGPT, Cursor or any MCP client read a modded Minecraft crash, find the right file of a mod for your version, and check what mods did in the Modkeel lab. No API key.

https://api.modkeel.com/mcp

Streamable HTTP. Also in the MCP registry as com.modkeel/modkeel, and on Smithery.

Tools

  • diagnose_crash

    Give it a crash report or latest.log. It returns the mod most likely behind the crash, why, how sure it is, and how to fix that kind of crash. Same analyzer as the crash page. The text is read and dropped, never stored.

  • search_mods

    Finds a mod's id from its name, like "Entity Culling" → entityculling, and lists the mods the lab has data on and the versions they were tested on.

  • get_mod_info

    What a mod is and where to get it: its Modrinth page (summary, loaders, the versions its author lists, client or server side, links) next to what the lab saw it do.

  • find_mod_download

    The file to install for a mod on your Minecraft version and loader, with its link and the mods it needs. When the author has no build yet, a port the lab verified in one of its modpacks, or what you can do instead.

  • get_mod_runs

    What the Modkeel lab saw a mod do: the Minecraft versions where it ran on a server or client, or crashed, and the mods it ran with. By mod id, like sodium.

  • check_mod_pair

    Whether two mods ran together in the lab, clashed, or were never tested together. Untested means no run yet, not a conflict.

  • check_mod_list

    The same for a whole mod list or modpack in one call: what clashed, what crashed, and what the lab never tested.

Prompts

Ready-made requests your assistant can list: diagnose-crash (why did my game crash), check-modpack (will these mods work together) and update-modpack (move my mods to another Minecraft version).

Connect

Claude Code

claude mcp add --transport http modkeel https://api.modkeel.com/mcp

Claude, ChatGPT and other apps

Add a custom connector (in Claude: Settings, Connectors) with the URL above. No sign-in.

Cursor, VS Code and clients with a JSON config

{
  "mcpServers": {
    "modkeel": { "url": "https://api.modkeel.com/mcp" }
  }
}

Try it

Once connected, ask in plain words; the assistant picks the tool:

  • Why did my game crash? with a crash report pasted. No crash at hand? Use this sample crash (a test mod that crashes on purpose).
  • Is there Better Structures for Minecraft 26.2 Fabric?
  • Do Sodium and Iris work together?
  • Will Sodium, Iris, Lithium and Create work together on Fabric 1.21.1?
  • What is Distant Horizons?
