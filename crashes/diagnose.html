Minecraft crash report reader

Which mod crashed your game? Paste the crash report, the text that starts with ---- Minecraft Crash Report ----, or your latest.log, or drop the file here. Modkeel reads the error and names the mod that most likely caused it.

Find it in your instance folder: the newest file in crash-reports, or logs/latest.log when the game closed without a report.

How to read a Minecraft crash report

A crash report starts with ---- Minecraft Crash Report ----, then a joke line, the time and a Description such as "Mod loading failed" or "Ticking entity". The lines that matter come next: the exception (for example java.lang.NoClassDefFoundError or MixinApplyError) and the stack trace under it. Package names in that trace usually name the mod, and a mixin error names the mod's mixin config. Further down, the mod list shows each mod's version. Paste it above and Modkeel reads it for you; the crash help pages explain the common errors one by one.

What happens to your text

It goes to api.modkeel.com, is read in memory to find the mod, and is dropped: not stored, not logged. Crash reports can hold your user name in file paths; nothing of it is kept. Privacy.

Let the game tell you

The Modkeel Companion does this on the next start, with the jars in front of it, and offers to turn the mod off or go back to the mods that last worked. Free and open source, for Fabric, NeoForge and Forge.
