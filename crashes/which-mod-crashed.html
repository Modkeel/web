Find which mod crashed Minecraft

Open the newest crash report and read the error and the stack trace: they usually name the mod. If they do not, remove half the mods at a time. Or let the Modkeel Companion, a free mod, name the mod on the next start and turn it off in one click.

Updated October 3, 2026. Fabric, NeoForge and Forge.

1. Open the crash report

In your instance folder, open the newest file in crash-reports. With the official launcher it is in .minecraft/crash-reports. If the game closed without a report, open logs/latest.log and look near the end.

2. Read the lines that name the mod

  • The error. Under Description comes the exception. A mixin error names the mod's mixin config, a file named <modid>.mixins.json. A missing class points to a library mod that is missing or the wrong version.
  • The stack trace. The lines starting with at under the error. Package names there, such as net.caffeinemc.mods.sodium, usually name the mod. The highest one that is not Minecraft or Java is the best lead.
  • Mod loading screens. "Incompatible mods found" or "Mod loading has failed" list the mods by name: mod loading failed explains each message.

3. No mod named? Remove half

Move half the mods out of the mods folder and start the game. If it still crashes, the cause is in the half left in; if not, in the half you took out. Keep halving: with 100 mods, about seven tries find the one. Keep each library mod together with the mods that need it, or the game stops for a different reason.

Let the game name it

The Modkeel Companion is a free, open source mod for Fabric, NeoForge and Forge. When the game crashes, the next start says which mod most likely did it, how sure Modkeel is and why, and one button turns that mod off, or goes back to the mods that last worked. It copies each world before it loads with different mods, so trying a fix never costs the world.

Questions

Where is the Minecraft crash report?

In the crash-reports folder of your instance (or of .minecraft for the official launcher), named crash-date-time-client.txt. If the game closed without one, use logs/latest.log.

Is there a mod that tells you which mod crashed the game?

Yes. The Modkeel Companion, a free and open source mod for Fabric, NeoForge and Forge, says on the next start which mod most likely caused the crash, how sure it is and why, and offers to turn that mod off or go back to the mods that last worked. It also copies each world before it loads with different mods.

The crash report names no mod. What now?

Remove half the mods and start the game. If it still crashes, the cause is in the half left in; if not, in the half you took out. Keep halving: with 100 mods, about seven tries find the one. Keep library mods that others need together with them.
