Lab data

Mods tested on Minecraft 26.3

Sodium mc26.3-0.9.3-alpha.1-fabric and Iris Shaders 1.11.7+26.3-fabric ran together in a client benchmark on Minecraft 26.3 in the Modkeel lab. Releases of 13 mods, among them Bobby, Chat Patches and CustomSkinLoader, made for an older Minecraft version did not start on 26.3 in the Modkeel lab: use a release made for 26.3. 25 mod releases started in real Minecraft 26.3 games in the Modkeel lab, among them Sodium, Iris Shaders, Lithium, FerriteCore and Entity Culling. The Modkeel lab also ran 11 pairs of mods in the same game.

Lab data as of October 5, 2026. 25 releases ran, 11 pairs, 13 older releases did not start, 19 ports.

What the lab measured on 26.3

Frame rate on Minecraft 26.3 with each mod, against the same game without mods.

Sodium raised the frame rate 55% with 300 mobs in view (94 to 145 FPS), 23% over terrain (234 to 288 FPS) and 78% with 300 mobs behind a wall (144 to 256 FPS).

Iris Shaders, which runs on Sodium and had no shader pack loaded, raised the frame rate 56% with 300 mobs in view (94 to 146 FPS), 13% over terrain (234 to 264 FPS) and 73% with 300 mobs behind a wall (144 to 250 FPS).

Entity Culling raised the frame rate 110% with 300 mobs behind a wall (144 to 303 FPS).

Lithium, ImmediatelyFast and More Culling did not change the frame rate with 300 mobs in view, over terrain or with 300 mobs behind a wall by more than runs without mods differed.

How it was measured: a real Fabric client on a laptop with a GeForce GTX 1650 and a Core i7-10750H (an entry-level gaming laptop from 2020) joined the same world at 1280x720, render distance 24, VSync off. Each number is the median second of 20-second scenes over 2 to 4 runs. Runs without mods differed by up to 15%, so smaller changes are not counted. Frame rates depend on the computer: on a faster one the numbers here are usually higher. The percentage is the better guide, but it moves too: mods that cut rendering work (Sodium, More Culling) gain most when the graphics card is the limit, and mods that cut entities or game logic (Entity Culling, Lithium) when the processor is. Some effects belong to one GPU brand: Sodium's drop with mobs on 1.21.1 and 1.20.1 only happens on NVIDIA cards. Raw data: every run's frame rate per second, Minecraft and loader versions, GPU and driver, loaded mods and the SHA-1 of each jar, which Modrinth matches to the exact release.

Server optimizers on 26.3

The lab ran 15 server optimizers on Minecraft 26.3, each alone on a fresh Fabric server with only Fabric API and Chunky, and timed the same scenes every run: how long the server takes to start, a tick with 400 mobs, a 64 by 64 redstone wire grid switched 100 times, and generating 960 by 960 blocks of new terrain, plus the memory in use after starting and after the new terrain. A mod counts as better or worse on a scene only when every one of its runs beat, or lost to, every one of the 4 runs without it.

Memory after start: FerriteCore (-6%) and ModernFix-mVUS (-5%) beat every run without them; Moonrise (+76%), Lithium (+6%), C2ME (+5%) and Async (+4%) lost to every one.

400 mobs: Async (-62%), Lithium (-52%), Moonrise (-18%) and LazyAI (-9%) beat every run without them.

Redstone: Alternate Current (-81%), Lithium (-37%) and Moonrise (-18%) beat every run without them; Async (+20%) and FerriteCore (+6%) lost to every one.

New terrain: C2ME (-15%), ScalableLux (-10%), Lithium (-5%) and ModernFix-mVUS (-5%) beat every run without them.

Memory after new terrain: C2ME (-56%) and Moonrise (-19%) beat every run without them; ScalableLux (+118%) lost to every one.

The five most common together (Lithium, C2ME, FerriteCore, ScalableLux and Very Many Players) beat every run without them on 400 mobs (-52%), redstone (-27%), new terrain (-24%) and memory after new terrain (-51%); they lost to every one on memory after start (+8%).

Fast Noise, Krypton, Ksyxis, ServerCore, Structure Layout Optimizer and Very Many Players beat or lost to no scene clearly: on a plain server the benchmark cannot tell what they change.

A plain server has none of the mods a big modpack loads, and no players: an optimizer that does nothing here can still help a busy server, and its cost here is what it adds to every server.

About this data

Loaded a world: a real Minecraft client started with the mod and joined a world. Server started: a real server finished starting with it. Benchmark: it ran through a timed lab scene. Did not start: the game stopped before it was playable.

Each row is one run in the Modkeel lab, matched to the exact file that ran: other files may behave differently. A mod or pair missing here was not tested yet; that is not a conflict.
