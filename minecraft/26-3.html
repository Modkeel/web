About this data

Loaded a world: a real Minecraft client started with the mod and joined a world. Server started: a real server finished starting with it. Benchmark: it ran through a timed lab scene. Did not start: the game stopped before it was playable.

Each row is one run in the Modkeel lab, matched to the exact file that ran: other files may behave differently. A mod or pair missing here was not tested yet; that is not a conflict.
