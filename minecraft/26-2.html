Lab data

Mods tested on Minecraft 26.2

Sodium mc26.2-0.9.2-fabric and Iris Shaders 1.11.4+26.2-fabric ran together in a client benchmark on Minecraft 26.2 in the Modkeel lab. Releases of 16 mods, among them Athena, Dynamic Trees and End Remastered, made for an older Minecraft version did not start on 26.2 in the Modkeel lab: use a release made for 26.2. 24 mod releases started in real Minecraft 26.2 games in the Modkeel lab, among them Sodium, Iris Shaders, Lithium, FerriteCore and Entity Culling. The Modkeel lab also ran 16 pairs of mods in the same game.

Lab data as of October 5, 2026. 24 releases ran, 16 pairs, 16 older releases did not start, 22 ports.

What the lab measured on 26.2

Frame rate on Minecraft 26.2 with each mod, against the same game without mods.

Sodium raised the frame rate 64% with 300 mobs in view (109 to 179 FPS), 40% over terrain (277 to 388 FPS) and 95% with 300 mobs behind a wall (86 to 168 FPS).

Iris Shaders, which runs on Sodium and had no shader pack loaded, raised the frame rate 59% with 300 mobs in view (109 to 173 FPS), 35% over terrain (277 to 373 FPS) and 92% with 300 mobs behind a wall (86 to 165 FPS).

Entity Culling raised the frame rate 83% with 300 mobs behind a wall (86 to 157 FPS).

Lithium, ImmediatelyFast and More Culling did not change the frame rate with 300 mobs in view, over terrain or with 300 mobs behind a wall by more than runs without mods differed.

How it was measured: a real Fabric client on a laptop with a GeForce GTX 1650 and a Core i7-10750H (an entry-level gaming laptop from 2020) joined the same world at 1280x720, render distance 24, VSync off. Each number is the median second of 20-second scenes over 2 to 4 runs. Runs without mods differed by up to 17%, so smaller changes are not counted. Frame rates depend on the computer: on a faster one the numbers here are usually higher. The percentage is the better guide, but it moves too: mods that cut rendering work (Sodium, More Culling) gain most when the graphics card is the limit, and mods that cut entities or game logic (Entity Culling, Lithium) when the processor is. Some effects belong to one GPU brand: Sodium's drop with mobs on 1.21.1 and 1.20.1 only happens on NVIDIA cards. Raw data: every run's frame rate per second, Minecraft and loader versions, GPU and driver, loaded mods and the SHA-1 of each jar, which Modrinth matches to the exact release.

Server optimizers on 26.2

The lab ran 15 server optimizers on Minecraft 26.2, each alone on a fresh Fabric server with only Fabric API and Chunky, and timed the same scenes every run: how long the server takes to start, a tick with 400 mobs, a 64 by 64 redstone wire grid switched 100 times, and generating 960 by 960 blocks of new terrain, plus the memory in use after starting and after the new terrain. A mod counts as better or worse on a scene only when every one of its runs beat, or lost to, every one of the 8 runs without it.

Server start: Lithium (-6%) beat every run without it.

Memory after start: FerriteCore (-6%) and ModernFix-mVUS (-5%) beat every run without them; Moonrise (+82%), Lithium (+8%), C2ME (+8%) and Async (+4%) lost to every one.

400 mobs: Async (-60%), Lithium (-56%), Moonrise (-27%) and LazyAI (-16%) beat every run without them.

Redstone: Alternate Current (-85%), Lithium (-52%), Moonrise (-33%), ModernFix-mVUS (-12%), Ksyxis (-12%) and Fast Noise (-12%) beat every run without them; FerriteCore (+16%), Async (+15%) and ServerCore (+7%) lost to every one.

New terrain: C2ME (-52%) and Moonrise (-24%) beat every run without them; Async (+8%) and ModernFix-mVUS (+6%) lost to every one.

Memory after new terrain: C2ME (-54%) beat every run without it; ScalableLux (+160%), Moonrise (+60%) and Lithium (+29%) lost to every one.

The five most common together (Lithium, C2ME, FerriteCore, ScalableLux and Very Many Players) beat every run without them on 400 mobs (-48%), redstone (-34%), new terrain (-55%) and memory after new terrain (-49%); they lost to every one on memory after start (+11%).

Krypton, Structure Layout Optimizer and Very Many Players beat or lost to no scene clearly: on a plain server the benchmark cannot tell what they change.

A plain server has none of the mods a big modpack loads, and no players: an optimizer that does nothing here can still help a busy server, and its cost here is what it adds to every server.

How much FPS does Sodium add on Minecraft 26.2?

About this data

Loaded a world: a real Minecraft client started with the mod and joined a world. Server started: a real server finished starting with it. Benchmark: it ran through a timed lab scene. Did not start: the game stopped before it was playable.

Each row is one run in the Modkeel lab, matched to the exact file that ran: other files may behave differently. A mod or pair missing here was not tested yet; that is not a conflict.
