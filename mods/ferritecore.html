FerriteCore on Minecraft 1.20.1 to 26.3

On a plain Minecraft 26.3 server in the lab's benchmark, FerriteCore beat every run without it on memory after start (-6%); it lost to every one on redstone (+6%).

FerriteCore releases started in real Minecraft 26.3, 26.2, 1.21.11, 1.21.1 and 1.20.1 games in the Modkeel lab. It ran in the same game as 8 other mods, among them Lithium, Entity Culling, ModernFix and Concurrent Chunk Management Engine (Fabric).
