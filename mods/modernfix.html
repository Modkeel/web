ModernFix on Minecraft 1.20.1 to 26.3

On a plain Minecraft 26.3 server in the lab's benchmark, ModernFix-mVUS beat every run without it on memory after start (-5%) and new terrain (-5%).

ModernFix releases started in real Minecraft 26.3, 26.2, 1.21.1 and 1.20.1 games in the Modkeel lab. It ran in the same game as 7 other mods, among them Lithium, FerriteCore, Entity Culling and Concurrent Chunk Management Engine (Fabric).
