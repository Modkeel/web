ScalableLux on Minecraft 1.21.1, 26.2 and 26.3

On a plain Minecraft 26.3 server in the lab's benchmark, ScalableLux beat every run without it on new terrain (-10%); it lost to every one on memory after new terrain (+118%).

ScalableLux releases started in real Minecraft 26.3, 26.2 and 1.21.1 games in the Modkeel lab. It ran in the same game as 7 other mods, among them Lithium, FerriteCore, Entity Culling and ModernFix.
