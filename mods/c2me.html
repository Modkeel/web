Concurrent Chunk Management Engine (Fabric) on Minecraft 1.20.1, 26.2 and 26.3

On a plain Minecraft 26.3 server in the lab's benchmark, C2ME beat every run without it on new terrain (-15%) and memory after new terrain (-56%); it lost to every one on memory after start (+5%).
