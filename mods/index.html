Mods the Modkeel lab ran

Each page shows which releases of a mod started in real Minecraft games in the lab, which mods ran in the same game with it, and what it changed in the frame rate or on a server where the lab measured it. Most searched mods first.

Lab data as of October 15, 2026.

  • Sodium

    Its biggest frame rate change in the Modkeel lab: on Minecraft 1.20.1, Sodium raised the frame rate 130% over terrain (210 to 482 FPS) and 27% with 300 mobs behind a wall (55 to 70 FPS); it lowered the frame rate 14% with 300 mobs in view (82 to 70 FPS), because on Windows with an NVIDIA card Sodium turns on a driver workaround against crashes that makes each draw call wait, and this version draws mobs of mixed kinds in many small draw calls.

  • Iris Shaders

    Its biggest frame rate change in the Modkeel lab: on Minecraft 1.20.1, Iris Shaders, which runs on Sodium and had no shader pack loaded, raised the frame rate 105% with 300 mobs in view (82 to 167 FPS), 127% over terrain (210 to 475 FPS) and 178% with 300 mobs behind a wall (55 to 153 FPS).

  • Lithium

    On a plain Minecraft 26.3 server in the lab's benchmark, Lithium beat every run without it on 400 mobs (-52%), redstone (-37%) and new terrain (-5%); it lost to every one on memory after start (+6%).

  • FerriteCore

    On a plain Minecraft 26.3 server in the lab's benchmark, FerriteCore beat every run without it on memory after start (-6%); it lost to every one on redstone (+6%).

  • Entity Culling

    Its biggest frame rate change in the Modkeel lab: on Minecraft 26.1.2, Entity Culling raised the frame rate 143% with 300 mobs behind a wall (103 to 250 FPS).

  • ModernFix

    On a plain Minecraft 26.3 server in the lab's benchmark, ModernFix-mVUS beat every run without it on memory after start (-5%) and new terrain (-5%).

  • ImmediatelyFast

    Its biggest frame rate change in the Modkeel lab: on Minecraft 1.21.1, ImmediatelyFast raised the frame rate 40% with 300 mobs in view (103 to 144 FPS) and 28% with 300 mobs behind a wall (85 to 109 FPS).

  • Mod Menu

    Ran on Minecraft 1.20.1 and 1.21.11, in the same game as 6 other mods; nothing measured yet.

  • Concurrent Chunk Management Engine (Fabric)

    On a plain Minecraft 26.3 server in the lab's benchmark, C2ME beat every run without it on new terrain (-15%) and memory after new terrain (-56%); it lost to every one on memory after start (+5%).

  • Krypton

    Ran on Minecraft 1.20.1 and 26.3, in the same game as 7 other mods; nothing measured yet.

  • LambDynamicLights - Dynamic Lights

    Ran on Minecraft 1.20.1 and 1.21.11, in the same game as 6 other mods; nothing measured yet.

  • More Culling

    Ran on Minecraft 1.20.1 and 26.3, in the same game as 6 other mods; nothing measured yet.

  • ScalableLux

    On a plain Minecraft 26.3 server in the lab's benchmark, ScalableLux beat every run without it on new terrain (-10%); it lost to every one on memory after new terrain (+118%).

  • Sodium Extra

    Ran on Minecraft 1.20.1 and 1.21.11, in the same game as 6 other mods; nothing measured yet.

  • Very Many Players (Fabric)

    Ran on Minecraft 1.20.1 and 26.3, in the same game as 7 other mods; nothing measured yet.
