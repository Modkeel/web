Privacy

Nothing is sent unless you choose to share

The Modkeel Companion works fully offline. It reaches the internet only to send what you ticked, and the screen shows you every field before it goes.

Updated October 9, 2026. Applies to Modkeel Companion 0.2.0 and later; 0.1.0 sends nothing at all.

What is sent, and when

  • A crash report, only when you tick Help other players on the crash screen: Minecraft, loader and Java versions, OS name, memory, the installed mods (id, version and file hash), the error and its stack frames, the suspected mods and the fix you picked.
  • How that fix went, for a crash you shared: whether it held or the same crash came back, and how much the suspected mods were played afterwards.
  • Play sessions, only if you also turn on Also share play sessions: minutes played, whether the game crashed, the worst lag spikes and the mods whose code ran during them. Turn it off any time in Modkeel > Settings.
  • A random install token that links those reports together. It is created on the first share and kept in modkeel/install.txt.

What is never sent

  • Your name, Minecraft account, world names or chat.
  • File names or paths (they can contain a user name), logs or the crash report file.
  • Anything at all, if you never tick a share option.

Before a report leaves, What is sent? lists every field in plain words and Show exact data shows the report itself. Modkeel's screen keeps the last 50 reports sent, with their contents.

Where it goes

Reports go to api.modkeel.com, a Cloudflare Worker with a Cloudflare D1 database. IP addresses are not stored: to limit abuse, the server keeps a hash of the IP with a secret that changes every day, and removes even that after 30 days. There is no endpoint that lists or exports reports.

The crash analyzer on this site

Text you paste into the crash analyzer goes to api.modkeel.com, is read in memory to name the mod behind the crash, and is dropped: it is not stored or logged, and is not one of the reports above. Only the same hashed IP limit applies.

The MCP server for AI assistants

The MCP server at api.modkeel.com/mcp needs no account or key. A crash report or log an assistant passes to diagnose_crash is handled like the crash analyzer above: read in memory and dropped, never stored or logged. search_mods, get_mod_runs, check_mod_pair and check_mod_list only read the public lab data. get_mod_info and find_mod_download also ask Modrinth about the mod named, sending only the mod, Minecraft version and loader, never your IP. None of them keep anything about the request. Only the same hashed IP limit applies.

What it is used for

To learn which mods crash with which, and which fixes work, so Modkeel can name the cause of a crash more surely for every player. Reports are not sold, and the mod has no ads or trackers.

Stop or start over

  • Untick Help other players and turn off play sessions: nothing more is sent.
  • Delete modkeel/install.txt in your game folder: the next share gets a new token, unlinked from the old reports.
  • To have the reports of a token deleted, email the token to privacy@modkeel.com. The token is not linked to who you are; we delete its reports and reply when it is done.
