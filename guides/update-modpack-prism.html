Update a modpack in Prism Launcher without losing your world

Prism already does the hard part: it keeps instances apart, so the new version goes in a copy and the old instance, with its world, stays as it was. Copy the instance with its saves, change the Minecraft version in the copy, update the mods, and open the world there only after the mods are sorted. The Modkeel Companion adds the way back inside the new instance.

Written October 17, 2026, against Prism Launcher's own menus. Fabric, NeoForge, Forge and Quilt instances.

Step by step

  1. Copy the instance. Right-click it and choose Copy. Keep Copy saves ticked. If you turn on symbolic or hard links to save space, also tick Don't link saves; otherwise both instances share one world folder, and the new version upgrades the old instance's world as well. Name the copy after the version, for example "My pack (26.3)".
  2. Change the Minecraft version in the copy. Edit, Version, select Minecraft, Change Version. Then select the loader (Fabric Loader, NeoForge, Forge) and Change Version again, to one made for the new Minecraft.
  3. Update the mods. In Mods, press Check for Updates. Prism looks for a release of each mod made for the new version and loader and lists what it will replace.
  4. Look at what it could not update. Two kinds of jar stay as they were: ones you dropped into the mods folder by hand (Prism has no metadata for them), and mods whose author has not released for the new version yet. An old file left in a new version usually stops the game from starting. Find those below before you open the world.
  5. Add the Modkeel Companion to the new instance and open the world. It copies the world before it loads with the new mods, and if the game crashes, the next start names the mod that most likely caused it and turns it off in one click. The old instance is still there if you want to stop and wait.

Every jar, including the ones Prism cannot update

modkeel move, a free open source command, does steps 2 to 4 from the mods folder itself. It only reads the old instance: each jar is identified by its hash on Modrinth and CurseForge, so jars added by hand count too, and each gets the build made for the new version. With a Prism instance it then adds "name (version)" next to the old one, with its memory and Java settings, configs, resource packs and shader packs; worlds are left for you to copy, because opening one on a new version upgrades it for good.

On October 17, 2026 we moved The Essentials Pack, 29 Fabric mods on Minecraft 1.21.11 (Sodium, Iris, Lithium, Simple Voice Chat, WorldEdit, Carpet and more), to 26.2 and to 26.3. Every one of the 29 had an official build for each version, Text Placeholder API came along as a dependency, and nothing had to be compiled. When a mod has no build for the new version, move tries an older build of it that still passes its checks there, then community builds, and says which one it used. When a mod has nothing, every option for a mod that is not updated.

move writes a new Prism (or MultiMC) instance only; for the Modrinth App and CurseForge it puts the pack in a folder, because those launchers keep their instances in their own database.

Keep the way back inside the new instance

The Modkeel Companion is a free, open source mod for Fabric, NeoForge and Forge. It copies each world before it loads with different mods; if the game then crashes, the next start names the mod that most likely caused it, how sure it is and why, and turns that mod off or goes back to the mods that last worked in one click. It has no mixins, so it cannot be what breaks a pack.

Questions

How do I update a modpack to a new Minecraft version in Prism Launcher?

Right-click the instance and choose Copy, with Copy saves ticked. In the copy, open Edit, Version, select Minecraft and press Change Version, then do the same for the loader. In Mods, press Check for Updates. Open a copy of the world first, and keep the old instance until the new one has run for a while.

Does Prism's Check for Updates find a build for the new Minecraft version?

For mods Prism downloaded itself, yes: it looks for a release made for the instance's Minecraft version and loader. Jars you dropped into the mods folder by hand carry no metadata, so Prism cannot update them, and a mod with no release for the new version keeps its old file, which usually will not start there.

Will copying a Prism instance copy my worlds?

Yes when Copy saves is ticked, which is the default. If you turn on symbolic or hard links to save space, also tick Don't link saves: otherwise both instances share the same world folder, and opening it on the new version upgrades the old instance's world too.
