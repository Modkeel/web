A mod hasn't updated to the new version

A new Minecraft version is out and a mod you need has no release for it. You can wait, stay where you are, swap it for another mod, or use a build that was checked on the new version: an older one that still runs, or a community port.

Updated October 15, 2026. Fabric, NeoForge and Forge.

First, check you didn't miss a release

  • Look on every site. Authors sometimes publish on Modrinth, CurseForge or GitHub releases first, and the others follow days later.
  • Check the other loaders. A mod may be out for Fabric on the new version before NeoForge, or the other way round.
  • Read the version list, not the title. A release made for 1.21.1 is not one for 1.21.10: they are different versions.

Your options

  1. Wait. The safest choice for a world that depends on the mod. Removing a mod deletes its blocks, items and creatures from the world the next time it saves, and adding it back does not restore them.
  2. Stay on the version you play. Keep your instance as it is and try the new version in a separate one. Nothing forces you to update.
  3. Swap it for an alternative. For performance, map or interface mods there is often another mod that does the same job on the new version. The lab data lists which releases ran on each version.
  4. Use an older build that still runs. On a patch release, a build made for the previous version sometimes runs unchanged, when the game code it touches did not change. In the Modkeel lab most did not: releases of 16 mods made for an older version did not start on Minecraft 26.2. Only use one that was checked on the new version.
  5. Use a tested community port. Someone may have built the mod for the new version from its source. Prefer one built from public source and started in a real game, like Modkeel's ports.

Whichever you pick, copy the world first, or let the Modkeel Companion do it: it copies each world before it loads with different mods.

Questions

Can I use a mod made for an older Minecraft version?

Sometimes, but usually not. In the Modkeel lab on October 3, 2026, releases of 16 mods made for an older version did not start on Minecraft 26.2. A few older builds do run on a patch release when the game code they touch did not change; check that before you rely on one, and open a copy of the world first.

How long do mod authors take to update?

It varies from days to months, and some mods never update. Libraries and performance mods tend to come first; large content mods often take longest.

Is it safe to use an unofficial port of a mod?

Only if you can tell where it came from and that it runs. Prefer ports built from public source, started in a real game on your version, and offered with a checksum. Modkeel's ports are built from the mod's own source on GitHub Actions and started in a real Minecraft server and client before they are listed.

What does Modkeel do when a mod hasn't updated?

The free Modkeel app (Windows, macOS, Linux) looks for a build of the mod that runs on your Minecraft version: the author's own build, an older build that still runs there, or a community port. It checks each one before you get it and says how it knows. It can also move a whole pack to another version beside the old one, never over it.
