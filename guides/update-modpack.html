Modpack guide

Update a modpack without losing your world

Copy the world first, swap every mod for a release made for the new Minecraft version, then open a copy of the world. The Modkeel Companion, a free mod, copies each world before it loads with different mods and, if the game crashes, names the mod that caused it.

Updated October 3, 2026. Fabric, NeoForge and Forge.

Why updates break worlds

  • Mods are made for one Minecraft version. In the Modkeel lab, releases of 16 mods made for an older version did not start on Minecraft 26.2, and releases of 13 did not start on 26.3.
  • A missing mod takes its things with it. When a world opens without a mod, the blocks, items and creatures from that mod are gone once the world saves. Adding the mod back later does not bring them back.
  • Mods that each work can clash together. Two mods that change the same game code can crash only when both are in the pack.

Update step by step

  1. Copy the world. Copy the world folder from saves somewhere safe, or let the Companion do it: it copies each world before it loads with different mods.
  2. Check each mod. On each mod's Modrinth or CurseForge page, look for a release made for the new version. The Modkeel lab data also says which releases started in real games on each version and which ran together.
  3. Wait for the mods your world depends on. If a mod that adds blocks or creatures has no release for the new version yet, update later, or play the new version in a new world.
  4. Make a new instance. In your launcher, make an instance for the new version with only releases made for it, and the loader version they ask for. Keep the old instance.
  5. Open a copy of the world. If it crashes, the crash report usually names the mod; turn that mod off and try again. If something is missing, go back to the copy.

Let the game keep the way back

The Modkeel Companion is a free, open source mod for Fabric, NeoForge and Forge. It copies each world before it loads with different mods; if the game then crashes, the next start names the mod that most likely caused it, how sure it is and why, and turns that mod off or goes back to the mods that last worked in one click. It has no mixins, so it cannot be what breaks a pack.

Questions

Do mods made for an older Minecraft version work on a newer one?

Usually not. In the Modkeel lab on October 3, 2026, releases of 16 mods made for an older version did not start on Minecraft 26.2, and releases of 13 mods did not start on 26.3. Use a release made for the version you play.

What happens to my world if I remove a mod?

Blocks, items and entities that came from that mod are gone the next time the world is saved, and adding the mod back does not restore them. Only a copy of the world made before the change brings them back.

Should I update to a new Minecraft version if my mods are not updated?

Not for a world you care about. Wait until the mods your world depends on have releases made for the new version, or play the new version in a new instance and keep the old one.
